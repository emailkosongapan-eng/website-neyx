# NEYX PANEL — Frontend

Frontend static terpisah dari API.

API yang digunakan:
https://nopeequupanel.priasologembira.web.id

## Deploy
Upload folder ini ke hosting static seperti Vercel, Netlify, Cloudflare Pages, GitHub Pages, atau hosting HTML biasa.

File utama:
- index.html = Login
- dashboard.html = Dashboard
- add-user.html = Add User
- add-token.html = Add Token
- users.html = Users
- tokens.html = Tokens
- assets/config.js = alamat API

Jika domain website berbeda dari API, API harus mengizinkan origin website tersebut lewat FRONTEND_URL dan CORS.
